# AOIDA runtime dependency assets

This repository preserves unmodified third-party runtime dependencies used by AOIDA. It contains no AOIDA application source, user data or credentials and is not a second product repository.

Versioned releases preserve the original archives, licence texts, exact upstream source/build snapshots and provenance manifests. Check both the archive and extracted executable against the recorded SHA-256 hashes before use. Do not replace existing release assets; publish a new reviewed version when updating a dependency.

The preserved FFmpeg build comes from [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds). Its own licence and build dependency notices apply. AOIDA invokes the standalone executable on the server; it is not a browser component.
